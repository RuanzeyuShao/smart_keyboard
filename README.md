## 一、项目简介

本项目实现了一个 **基于深度学习的围棋智能体系统**，涵盖：

- ✅ **完整围棋规则引擎（19×19）**
- ✅ **启发式自对弈数据生成**
- ✅ **卷积神经网络策略模型（Policy Network）**
- ✅ **监督式训练流程**
- ✅ **可视化 GUI 人机对弈界面**

项目目标并非复刻 AlphaGo 的完整 MCTS + Value 架构，而是构建一个**结构清晰、可扩展、适合教学与研究的围棋 AI 基线系统**，AI水平达到**野狐1d**水平

## 四、核心模块详解

---

### 4.1 Board.py —— 围棋规则引擎

**功能定位：**

- 提供完整合法的 19×19 围棋规则支持

**主要功能：**

- 落子合法性判断（占用 / 自杀 / 打劫 superko）
- 气（liberties）计算
- 提子逻辑
- 悔棋支持（历史棋盘）
- 中式数子 + 黑贴 7.5 目计分

**关键接口：**

```python
Go.place([x, y])   # x, y ∈ [1, 19]
```

返回值说明：

- `0`：落子成功
- `-2`：位置已占用
- `-3`：违反打劫（superko）
- `-4`：自杀禁手

---

### 4.2 g_d.py —— 启发式自对弈数据生成器（核心创新点）

**这是 README 升级后重点强调的模块**

#### 功能定位

> `g_d.py` 是一个**离线运行的启发式自对弈数据生成器**，用于生成“比随机更合理”的围棋监督学习样本。

可视为：
**规则围棋 AI + 人工经验 = 策略网络的老师**

---

#### 核心思想

- 枚举当前局面下的所有合法落点
- 使用启发式规则进行评估，例如：
  - 吃子收益
  - 气的增减
  - 邻近棋块强弱
  - 潜在领地倾向
- 从高评分候选点中采样，而非纯 argmax
- 生成更接近“人类初学/中级棋力”的对弈数据

---

#### 输出数据格式（.npz）

每个 `sample_x.npz` 包含：

- `inX`：`(N, 19, 19, 44)`网络输入特征（多通道棋盘表示）
- `y`：`(N, 361)`one-hot 落子标签
- `wl`：
  `(N,)`
  胜负标记（1=胜方样本）

---

#### 使用方式

```bash
python g_d.py
```

运行后自动生成：

```
prof_dat_1/sample_*.npz
```

---

### 4.3 Player_Conv.py —— 策略网络（Policy Network）

**模型类型：**

- 多层卷积神经网络（CNN）
- 输出 361 维 Softmax 概率分布

**输入：**

- 19×19×44 的多通道棋盘特征
- 包含：
  - 当前/对手棋子
  - 气信息
  - 历史 8 手
  - territory 邻域特征

**输出：**

- 每个交叉点为“下一步落子概率”

---

### 4.4 train_model.py —— 模型训练流程

**训练模式：**

- 监督学习（Supervised Learning）
- 训练目标：
  `棋盘状态 → g_d.py 生成的合理落子`

**训练流程：**

1. 检查 / 初始化权重 `w_RL.npz`
2. 读取 `prof_dat_1/sample_*.npz`
3. 只使用胜方样本进行训练
4. Top-1 / Top-5 准确率评估
5. early stopping + 梯度裁剪
6. 保存最优权重

```bash
python train_model.py
```

---

### 4.5 UI.py —— 图形化人机对弈系统

**功能：**

- Tkinter GUI 棋盘
- 点击落子
- AI 自动应对
- 落子提示（不落子）
- 悔棋 / 停一手
- 实时估算胜负

**运行方式：**

```bash
python UI.py
```
